# Working on FireRed HD-2D

Development work for the HD-2D fork should happen on the `hd2d-development` branch.

Start by reading:
- `AGENTS.md`
- `docs/HD2D_ROADMAP.md`
- `docs/3d-mode.md`
- `docs/development.md`

The first goal is not all of Kanto. It is a polished vertical slice covering Pallet Town, Oak's Lab, Route 1, Viridian City, the Pokémon Center, and the Mart.

Use your own legally obtained FireRed ROM locally. ROMs, saves, save states, and extracted copyrighted game assets must never be committed.
